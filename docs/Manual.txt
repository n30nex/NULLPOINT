NULLPOINT // EXPANDED NATIVE 96K

RUN
Open NULLPOINT.exe and press Enter. Requires 64-bit Windows 10/11 and an
OpenGL 2.1 graphics driver with framebuffer support. No installation,
internet connection, external game assets, or extra DLL downloads.

MISSION
Use E near each of the three power relays. After all three are offline, the
containment gate opens. Destroy the Warden, reach the green extraction bay,
and hold it for six seconds while defending against reinforcements.
Leaving the bay reduces uplink progress.

OPTIONAL EXPLORATION
The Service and Armory wings each hold an overclock cell; a third is inside
containment. Purple cells permanently add 15% of base weapon and grenade
damage, restore 25 health, and grant two grenades. All three give +45% damage.
The full route has 39 enemies including the Warden and reinforcements.

COMBAT
All three weapons are available from the start. The carbine is automatic,
the shotgun fires nine pellets, and the ion lance deals heavy direct damage.
G throws a grenade with a 2.1-second fuse. Grenades bounce, slow on impact,
and damage nearby enemies and the player. Stay clear of your own blast.
Orange barrels can be shot or detonated by explosions. Chain reactions
respect walls. Destroyed barrels stop blocking movement. Munitions pickups
refill all weapon reserves and add a grenade, up to eight.

CONTROLS
W / S        Forward / backward
A / D        Strafe left / right
Mouse        Standard look
Left click   Fire
Right click  Aim
1 / 2 / 3    Carbine / shotgun / ion lance
Mouse wheel  Cycle weapons
G            Throw grenade
R / E        Reload / interact
Shift        Sprint
Space        Jump
Ctrl         Crouch
Tab (hold)   Facility map
Escape       Pause / resume and release mouse
F11          Borderless fullscreen
M / End      Mute / quit

Arrow keys aim and F fires without a mouse. Choose difficulty with left/right
on the title screen. In the pause menu, Q changes render quality, minus/plus
changes mouse sensitivity, and N restarts. Alt-Tab pauses automatically.
The --performance option starts with reduced internal render resolution.

MOVEMENT
Movement accelerates and slows smoothly. Simulation runs at 120 Hz,
independently of rendering. Jumping can land on crate tops. Jump input is
briefly buffered, with a short allowance when stepping off an edge.

SIZE AND CONTENT
The complete playable executable is 93,696 bytes: 2,304 below the strict
96,000-byte limit, and 1,536 smaller than the previous version. Native code
is not packed. Embedded shader text expands in memory using a Windows API.
Geometry, materials, music and sound are generated; Windows provides fonts
and DLLs. Screenshots, source and developer tests are separate optional files.

Graphics include beveled meshes, metal/paint shading, HDR bloom, contact
shading, half-resolution planar reflections, headlamp shadows, light haze,
animated machinery, enemy limbs, weapon motion and impact particles.

VALIDATION
Passed 26 gameplay/physics checks, 20 camera/input checks, native renderer
checks and eight capture checks. Scripted campaigns on all three difficulties
collect every upgrade, throw grenades, defeat all 39 enemies and extract.
Perfect scripted aim is not a human balance assessment. Full and Performance
rendering both passed. See docs/RESEARCH.md for measurements and limitations.

BUILD / TEST
Source requires Python 3 and x86_64 MinGW-w64 GCC on Windows. No Python
packages are required. Run build.ps1 for the playable game; it rejects an
oversized candidate before replacing the destination. Run verify.ps1 for
all development checks. Separate developer test binaries may exceed 96 KB;
only NULLPOINT.exe is the game entry. The shipping --verify option writes
graphics.txt and eight BMP captures in the current writable directory.
Developer builds also support --selftest and --playtest, optionally with
--operative or --veteran.
